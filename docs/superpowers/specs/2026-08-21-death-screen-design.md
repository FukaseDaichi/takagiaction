# 死亡画面（自席リザルト＋闇サイト統合）設計

見本画像: `m/result.png`。この見た目を DOM/CSS＋Codex 生成画像で再現し、
死亡時のテキストリザルト（`terminal_show_result`）とテキスト闇サイトメニュー
（`menu.ts`）を 1 枚の全画面 UI に統合して置き換える。

## 画面構成

死亡時と初回起動時（イントロ後）の 2 モードを持つ 1 画面。

- **左上見出し**: 死亡時「死亡したよ、高木。」＋「救護ドローンが君を回収して、自席へ戻した。」。
  初回起動時は「自席の端末。」＋「闇サイトに接続した。」に差し替え、
  「今回の記録」と状態パネル（赤）を非表示にする。
- **今回の記録**: 到達深度 / 生存時間（mm:ss）/ 撃破数 / 喫煙回数 / ダミー踏み。
  すべて実データ（下記「新規統計」）。
- **ヒーローイラスト**: Codex 生成 PNG。ラップトップの
  「闇サイト [Y-EXCHANGE] 接続中...」表示はイラストに焼き込み。
- **状態パネル（赤）**: 死因メッセージ 2 種
  （ニコチン切れ死「ニコチン、限界です。しっかり整えて、また潜れ。」／
  敵死「やられたよ、高木。次はもっと慎重に。」）、
  HP（死亡時の実値。死亡なので 0/5）、ニコチン %（死亡時の実値）、
  人体シルエット画像、手の震え・集中力・吸いたい気持ち
  （死亡時のニコチン段階から導出。limit 帯 = MAX / 崩壊 / MAX、
  withdrawal 帯 = 大 / 低下 / 大、それ以下の段階は死因が敵なので 小 / 正常 / 小）。
- **右カラム**: ヤニ残高ヘッダ（「ヤニは闇サイトに送ると見返りが届く。」）＋
  恒久強化 5 行。各行はアイコン・名前・説明・Lv x/max・ドットピップ
  （最大数ぶん描き、現レベルぶん点灯）・コスト・[+] ボタン。
  説明文は現行方針どおり `meta.ts` の getter から累積効果を引き、
  式をメニュー側に書き写さない。残高不足の行は暗くしてクリック無効。
- **下段**: 次の潜入準備（推奨深度 = 自己ベスト F+、
  「次はもっと深く、もっといい一服を。」）／所持アイテム欄は簡略化 —
  予備の一本 ×残数（強化レベル）のスロット＋残りは EMPTY 表示。
  救急箱・グレネード等の新アイテムは実装しない ／「地下へ戻る」大ボタン。
- **フッター**: 実際に効くキーだけ表示:
  `◀▶ 強化選択 / [Enter] 強化する / [Tab] 項目切替 / [Esc] 地下へ戻る`。
  見本の [R] ステータス詳細は対応画面がないため置かない（唯一の意図的差分）。

## 操作

- マウス: [+] クリックで購入、「地下へ戻る」クリックで降下。
- キーボード: ↑↓（または ◀▶）で強化行を選択、Enter で購入、
  Tab で強化リスト⇄地下へ戻るのフォーカス切替、Esc で地下へ戻るへ直行。
- 購入成功時は既存の pickup 効果音、降下時は beep を流す（現行 menu.ts と同じ）。

## 新規統計（state.ts）

- `run_time`: `game_tick` で `game_running` 中のみ加算。
- `smoke_count`: 喫煙所での一服完了＋予備の一本使用で +1。
- `dummy_count`: ダミー喫煙所に触れた回数。同一ダミーの重複カウントなし。
- 死因（ニコチン切れ / 敵）と死亡時の HP・ニコチン値を `run_end` 経由で画面に渡す。

## 強化の 10 段化（meta.ts 再設計）

| 項目 | 最大 | 効果曲線 |
|---|---|---|
| 肺活量 | 10 | 最大ゲージ 100 + 10×Lv（最大 200） |
| ニコチン耐性 | 10 | 減少 −4%×Lv（最大 −40%） |
| 嗅覚 | 10 | 発動しきい値 30% + (30/9)%×(Lv−1)（Lv10 で 60%）、Lv10 で距離表示 |
| 火力 | 10 | 射撃間隔 −5%×Lv（最大 −50%） |
| 予備の一本 | 5 | 本数 = Lv |

- 嗅覚の発動判定は段階（stage）ベースからニコチン比率ベースに変更する
  （`meta_sniff_active(ratio)`）。恒久ナビ化の禁止（しきい値上限 60%）は維持。
- コスト: `cost(lv) = 15 + 10×lv + 5×lv²`（15〜510）。
  10 段 4 項目 = 2,025/項目、予備 5 段 = 325、全解放合計 8,425。
- 数値はすべて調整可能な提案値。`docs/meta-progression.md` の
  釣り合いの記述（実効 2.143 倍・深度 37）も新曲線に合わせて書き直す。
- 保存データ: 既存セーブのレベル値は新最大以下なのでそのまま読める。
  マイグレーション不要。

## 画像アセット（Codex 生成 → `m/ui/`）

- ヒーローイラスト（椅子でぐったりする高木＋ラップトップ）
- 強化アイコン 5 種（肺・脳・鼻・弾丸・煙草）

- 枠線・グロー・ドットピップ・バー・スキャンライン等は CSS で描画。
- Codex CLI の画像生成が使えない場合はその時点で報告して相談する。
