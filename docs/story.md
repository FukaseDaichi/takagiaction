# ストーリーと世界観

## 基本ストーリー

西暦2718年。喫煙は法律で禁止され（嗜好性燃焼物 全面禁止条例、2703年施行）、地上から喫煙所は完全に姿を消した。

愛煙家の**高木**は、閉鎖された巨大施設の地下に「まだ使える喫煙所が残っている」という噂を聞く。煙草を求めて施設へ侵入した高木だったが、警備ロボットに発見され、地下へ追い込まれてしまう。手持ちのニコチンは残りわずか。高木は離脱症状に耐えながら、各階に残された喫煙所を探して地下へ進んでいく。

目的は世界を救うことでも、施設の秘密を暴くことでもない。**ただ、一服したい。**

## ゲーム進行との対応

| ゲーム要素 | 世界観上の意味 |
| --- | --- |
| ニコチンゲージ | 高木の吸いたい気持ち |
| 敵 | 施設を巡回する禁煙監視ロボット |
| 喫煙所 | 過去に閉鎖された古い喫煙スペース |
| ダミー喫煙所 | 灰皿だけ撤去された跡地 |
| ヤニ | 残された吸い殻や煙草の燃えかす |
| 非常口 | 煙を感知すると開く旧式の防災扉 |
| 深度 | 高木が喫煙所を求めて潜った地下階数 |

一服すると煙感知器が作動し、非常口が開く。高木は警報を鳴らしながら、さらに地下へ逃げることになる。

## ローグライトの世界観上の説明

高木が倒れると、施設の救護ドローンによって地上の自席まで運び戻される。目を覚ました高木の自席の端末は、愛煙家の闇サイトに繋がっている。喫煙が非合法化された世界では吸い殻（ヤニ）そのものが禁制品として闇で価値を持ち、持ち帰ったヤニを送ると見返りが届く。装備を整えた高木は、再び地下へ向かう。前回より深く潜れば、もっといい喫煙所があるかもしれない。

恒久強化のフレーバー:

| 項目 | 意味 |
| --- | --- |
| 肺活量 | 闇サイトの怪しい訓練プログラム（吸い方の訓練） |
| ニコチン耐性 | 闇サイトの怪しい訓練プログラム（我慢の訓練） |
| 嗅覚 | 闇サイトの怪しい訓練プログラム（利き煙草）。切羽詰まるほど鼻が利く |
| 火力 | 闇サイトから届く物資 |
| 予備の一本 | 闇サイトから届く物資。こっそり浅く吸うため煙感知器には届かず、回復も半分止まり |

## オープニングの基準文

オープニングが伝えるべき内容の基準。現行の `terminal.ts` の文面は、これと同じ内容を生体モニタリング端末のログ形式で表現している。

> 西暦2718年。
> 喫煙所は、地上から消えた。
> だが高木は聞いた。
> 閉鎖施設の地下には、まだ火のつく灰皿がある。
> 残りニコチン、100%。
> 警備システム、作動。
> 高木は煙草を求めて、地下へ降りた。

## 声の使い分け

ゲーム中のメッセージは 2 つの声に分かれる。

| チャンネル | 声 | 担当 |
| --- | --- | --- |
| ターミナル（画面左上） | 施設・生体モニタリング端末 | 事実と指示（深度到達、非常口ロック解除、リザルト） |
| 吹き出し（自機頭上） | 高木の内心 | 目的・感情・切迫感（喫煙所を探す動機、ダミーへの悪態、ゲージ低下のつぶやき） |

セリフを書くときの規則:

- ターミナルはログ形式の文体、吹き出しは高木の一人称。初心者への「次に何をすべきか」は吹き出し側が高木の欲望として語る（例:「どこかに喫煙所があるはずだ……」）
- セリフは source/monologue.ts のプールに各 2〜3 種ずつ持ち、直前と同じ行は選ばれない
- ゲージ段階のつぶやきは悪化方向の遷移でのみ出す。改善（一服）では黙る。ただし離脱症状（ゲージ 30〜1%）以降は、遷移がなくても 10 秒に一度その段階のセリフをアンビエントとして繰り返す。10 秒は「離脱症状であることを忘れさせない頻度」と「同じセリフの繰り返しがうるさく感じない頻度」の折り合いで選んだ値
- 離脱症状以降は吹き出しに手の震え（`.tr` クラスによる振動）を付け続ける。段階のセリフと同じ、悪化を体感させるための効果
- 吹き出しの時間進行は setTimeout ではなくフレーム時間駆動。ターミナルの表示チェーンとは独立しており、互いに潰し合わない

## 全体のトーン

深刻なディストピアではなく、**本人だけは大真面目なSFコメディ**。高木は世界の謎に興味がなく、端末に重大そうな文章が表示されても反応は一貫している。

「それより、喫煙所はどこだ」

最深部や黒幕は置かない。地下にはまだ喫煙所があるらしい — それだけを信じて、高木は倒れるまで潜り続ける。この単純さが、無限スコアアタックと噛み合う。UIテキスト・演出を書くときは、世界の危機や陰謀をほのめかす文言を足さないこと。
