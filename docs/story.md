# ストーリーと世界観

## 基本ストーリー

西暦2718年。喫煙は法律で禁止され（嗜好性燃焼物 全面禁止条例、2703年施行）、地上から喫煙所は完全に姿を消した。

愛煙家の**高木**は、閉鎖された巨大施設の地下に「まだ使える喫煙所が残っている」という噂を聞く。煙草を求めて施設へ侵入した高木だったが、警備ロボットに発見され、地下へ追い込まれてしまう。手持ちのニコチンは残りわずか。高木は離脱症状に耐えながら、各階に残された喫煙所を探して地下へ進んでいく。

目的は世界を救うことでも、施設の秘密を暴くことでもない。**ただ、一服したい。**

## ゲーム進行との対応

| ゲーム要素 | 世界観上の意味 |
| --- | --- |
| ニコチンゲージ | 高木の吸いたい気持ち |
| 敵 | 施設を巡回する禁煙監視ロボット |
| ボス | 5 階ごとに降りてきて灰皿を撤去して回る大型作業機 |
| 喫煙所 | 過去に閉鎖された古い喫煙スペース |
| ダミー喫煙所 | 灰皿だけ撤去された跡地。**このボスが既に仕事を終えた場所** |
| ヤニ | 残された吸い殻や煙草の燃えかす |
| 非常口 | 煙を感知すると開く旧式の防災扉 |
| 深度 | 高木が喫煙所を求めて潜った地下階数 |
| 押収品コンテナ | セントリーが施設内で押収した禁制品の封入容器 |
| 装備 | 闇サイトで流通する怪しい通販商品と、押収された禁制品 |

一服すると煙感知器が作動し、非常口が開く。高木は警報を鳴らしながら、さらに地下へ逃げることになる。

## ローグライトの世界観上の説明

高木が倒れると、施設の救護ドローンによって地上の自席まで運び戻される。目を覚ました高木の自席の端末は、愛煙家の闇サイトに繋がっている。喫煙が非合法化された世界では吸い殻（ヤニ）そのものが禁制品として闇で価値を持ち、持ち帰ったヤニを送ると見返りが届く。装備を整えた高木は、再び地下へ向かう。前回より深く潜れば、もっといい喫煙所があるかもしれない。

恒久強化のフレーバー:

| 項目 | 意味 |
| --- | --- |
| 肺活量 | 闇サイトの怪しい訓練プログラム（吸い方の訓練） |
| ニコチン耐性 | 闇サイトの怪しい訓練プログラム（我慢の訓練） |
| 嗅覚 | 闇サイトの怪しい訓練プログラム（利き煙草）。切羽詰まるほど煙の残り香が分かり、鍛えれば吸い殻を溜めた清掃ドローンの回収槽や、押収品の箱の在り処まで嗅ぎ当てる |
| 火力 | 闇サイトから届く物資 |
| 予備の一本 | 闇サイトから届く物資。こっそり浅く吸うため煙感知器には届かず、回復も半分止まり |

装備（docs/equipment.md）の品名も同じ闇サイトの文体で書く。笑いどころは**大仰な商品名と実物のみすぼらしさのギャップ**にあり、名前が強くなるほど実物も本当に強くなる、という一貫性で成立させる。`MK-II` / `FINAL DRAG` のような疑似スペックと英字の商品名を日本語化しないのは、下の「固有名詞と疑似スペックは日本語化しない」と同じ規約である。

## オープニング

初回アクセスの OP は映画予告編の話法で構成する。「やつら」の正体を最後まで名指しせず、4 枚目まで神格化しておいて、5 枚目で高木が落とす。

> 1. （語り）「西暦2718年。やつらは違法となった。」
> 2. （語り）「地上から、すべてのやつらが消えた。」
> 3. （語り）「しかし一人の男が、地下にまだやつらが眠っているという噂を聞いた。」
> 4. （語り）「失われた人類の遺産。禁じられた聖域。最後の安息の地。」
> 5. （高木）「喫煙所だ。」

規則:

- 落ちは二段。言葉の落ち（三連呼の神格化 →「喫煙所だ。」）と絵の落ち（宗教画の光 → みすぼらしい実物の喫煙所）を 5 枚目で同時に決める。4 枚目までは「やつら」の映像的な正体（煙草・灰皿・喫煙所）を画面に出さない
- 語りの字幕は画面中央にセリフ体（明朝系）で出し、ターミナルの等幅アンバーと視覚的に区別する。高木のセリフはさらに別のスタイルで「これは中の人」と分かる形にする
- タイトル `TAKAGI ACTION` は起動画面に出さず、5 枚目の直後のタイトルドロップまで温存する。起動画面に置くのは原作クレジットの常設表示と「クリックで起動」だけ
- 音はブラウザの自動再生ポリシーにより最初のクリック後にしか鳴らせないため、OP 本編は必ずクリックの後に置く
- OP は全編、クリックまたはキーで即スキップでき、スキップ先は自席の端末である
- 操作説明は OP に置かず、自席の端末に常設する

## 声の使い分け

メッセージは 3 つの声に分かれる。語りは OP 専用で、ゲーム中に使うのはターミナルと吹き出しの 2 つである。

| チャンネル | 声 | 担当 |
| --- | --- | --- |
| OP 字幕（画面中央） | 語り（映画予告編のナレーション） | OP 限定。世界の前提を大仰に神格化して語る。「やつら」を名指ししない |
| ターミナル（画面左上） | 施設・生体モニタリング端末 | 事実と指示（深度到達、非常口ロック解除） |
| 吹き出し（自機頭上） | 高木の内心 | 目的・感情・切迫感（喫煙所を探す動機、ダミーへの悪態、ゲージ低下のつぶやき） |

セリフを書くときの規則:

- ターミナルはログ形式の文体、吹き出しは高木の一人称。初心者への「次に何をすべきか」は吹き出し側が高木の欲望として語る（例:「どこかに喫煙所があるはずだ……」）
- セリフは source/monologue.ts のプールに各 2〜3 種ずつ持ち、直前と同じ行は選ばれない
- ゲージ段階のつぶやきは悪化方向の遷移でのみ出す。改善（一服）では黙る。ただし離脱症状（ゲージ 30〜1%）以降は、遷移がなくても 10 秒に一度その段階のセリフをアンビエントとして繰り返す。10 秒は、離脱症状であることを忘れさせない頻度と、同じセリフの繰り返しがうるさく感じない頻度の両方に収まる間隔である
- 離脱症状以降は吹き出しに手の震え（`.tr` クラスによる振動）を付け続ける。段階のセリフと同じ、悪化を体感させるための効果
- 吹き出しの時間進行は setTimeout ではなくフレーム時間駆動。ターミナルの表示チェーンとは独立しており、互いに潰し合わない

## 全体のトーン

深刻なディストピアではなく、**本人だけは大真面目なSFコメディ**。高木は世界の謎に興味がなく、端末に重大そうな文章が表示されても反応は一貫している。

「それより、喫煙所はどこだ」

地下に終点は無い（`state.depth` に上限を持たせない）。まだ喫煙所があるらしい — それだけを信じて、高木は倒れるまで潜り続ける。この単純さが、無限スコアアタックと噛み合う。UIテキスト・演出を書くときは、世界の危機や陰謀をほのめかす文言を足さないこと。

画面に出る文言は日本語だが、**固有名詞と疑似スペックは日本語化しない。** 原作者名・`UNDERRUN`・`PHOBOSLAB.ORG` のような固有名詞や URL と、`MK-II` / `FINAL DRAG` のようなハードウェア風の文字列がそれで、施設の端末が吐いている生ログという体を保つのが役目。ここを訳すと、ターミナルが「プレイヤーに向けて書かれた説明文」に見えてしまい、事実はターミナルという住み分け（「声の使い分け」）が崩れる。
