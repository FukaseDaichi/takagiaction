# TAKAGI ACTION

[phoboslab/underrun](https://github.com/phoboslab/underrun)（js13kgames 2018 出品作 **UNDERRUN**）をベースに、日本語向けにアレンジしていくプロジェクトです。

見下ろし型（トップダウン）のアクションシューティング。舞台は喫煙が非合法化された近未来の施設。プレイヤーはニコチン切れと戦いながら喫煙所を探し、一服しては非常口を開けて次のフロアへ潜り続けるローグライトです。WebGL 製で、オリジナルはゲーム本体・グラフィック・BGM をすべて含めて **13KB 以下**という制約の中で作られています。

## ローカルでの起動

`source/main.ts` は TypeScript で書かれており、ブラウザは素の `.ts` を実行できません。Vite の開発サーバーが変換を行うため、`file://` で `index.html` を直接開いても動きません。Vite の開発サーバーを使ってください。

```bash
npm install
npm run dev
```

表示された URL（既定では `http://localhost:5173/`）を開きます。`source/` を編集すると自動でリロードされます。

起動するとターミナル風のイントロが流れます。**画面をクリックするとゲーム開始**です（音声再生のためにクリックが必要です）。

推奨環境: WebGL と Web Audio API に対応した最近のブラウザ（Chrome / Firefox / Safari / Edge）。

## 操作方法

| 操作 | キー / 入力 |
| --- | --- |
| 移動 | `W` `A` `S` `D` または `↑` `←` `↓` `→` |
| 射撃 | `スペース`（押しっぱなしで連射／約 0.1 秒間隔 = 毎秒 10 発） |
| 音声 ON / OFF | `M` |
| ゲーム開始 | 画面をクリック |

- 自機は 8 方向のスプライトで**進行方向**を向きます。
- `スペース` を**押している間は向きが固定**されます（射撃モード）。押したまま移動すれば、向きを保ったままの後退射撃やストレイフができます。離すと再び進行方向を向きます。移動していない間は最後の向きを維持します。
- 弾（プラズマ）は壁に当たると消えます。連射は押しっぱなしで OK です。
- 音声（BGM・効果音）は `M` で一括切り替えできます。GitHub Pages などでは既定 ON、`localhost` / `127.0.0.1` / `file://` での開発時は既定 OFF です。設定は保存されないので、リロードすると既定値に戻ります。

## ゲームのルール

### 目的

各フロアには本物の**喫煙所**が 1 か所と、見た目が同じ**ダミー**（灰皿撤去済み）が深度に応じて複数配置されています。喫煙所に**触れる**と自動で一服が始まり、2.5 秒間その場を動けなくなる代わりにニコチンゲージが全快します。

1. 一服が完了すると**非常口が開通**します
2. 非常口を通ると**深度が 1 進み、間取りが一新された次のフロア**へ移動します
3. 深度に**上限はありません**。ニコチン切れで力尽きるまで潜り続けます
4. **到達した深度がそのままスコア**になります

### ニコチンゲージ

画面左上の**タバコ**がニコチンゲージです。時間経過で常に燃えて短くなり、深度が進むほど燃えるのが速くなります。0 になっても即死はしませんが、段階が進むごとに行動が不利になります。

残量は紙の長さそのままで、燃えた分は灰として残るので満タンの位置が分かります。紙には**60% と 30% の位置に目盛りが印字**されていて、火種がそれを越えると段階が変わります（色ではなく位置で読めます）。60% を切ると百分率の数字も出ます。

| ゲージ残量 | 状態 | 効果 |
| --- | --- | --- |
| 100〜61% | 通常 | 変化なし |
| 60〜31% | そわそわ | 視界とミニマップの見える範囲が狭くなる |
| 30〜1% | 離脱症状 | 移動が遅くなり、射撃間隔が伸び、弾がばらけ、画面が細かく震える |
| 0% | 限界 | 2 秒ごとに HP が 1 減る |

ゲージを全快させられるのは喫煙所での一服だけです。被弾すると一服は中断されて進捗が失われますが、喫煙所自体は消費されないので**何度でも吸い直せます**。

### 体力とミス

| 項目 | 内容 |
| --- | --- |
| 最大 HP | 5。**削られたときだけ**タバコの下に ♥ が並びます（満タンに戻って 3 秒で消えます）。**フロアに入るたびに全回復した状態で始まります** |
| ダメージ | スパイダーの接触で 1、セントリーのプラズマ弾で 1、ニコチン切れ（限界状態）の継続ダメージで 2 秒ごとに 1 |
| 無敵時間 | 被弾後 2 秒間（自機が点滅します） |
| HP 0 のとき | ランが終了し、到達深度と撃破数が表示されます。クリックすると**新しいランが深度 1 から**始まります |

フロアの地形は**ラン開始時に引かれるシード**から手続き生成されるため、同じラン内で深度が違えば必ず間取りが変わり、ページを再読み込みして新しいランを始めても深度 1 の間取りが変わります。間取りを覚えて有利に進めるゲームにはなっていません。

### マップ（画面右上）

画面右上に**フロア全体のマップ**が常時表示されます。最初はすべて未探索の暗闇で、進むにつれて見えた範囲だけが描き込まれていきます。

| 表示 | 意味 |
| --- | --- |
| 暗いティール | 探索済みの床 |
| 明るいグレーブルー | 探索済みの壁 |
| オレンジ | 喫煙所（本物・ダミーとも同じ見た目） |
| 緑 | 非常口（一服完了で開通した後のみ表示） |
| 白 + 橙の点 | 自機の位置と向き |
| 淡い黄の点 | 吸い殻。嗅覚 Lv5 以上でのみ表示。未探索エリアにも出ます |
| 淡い青の点 | 清掃ドローン。嗅覚 Lv5 以上でのみ表示。未探索エリアにも出ます |
| 何も描かれない | 未探索 |

- 開示判定は**視線ベース**です。自機から一定半径内にレイを飛ばし、**壁で遮られた先は未探索のまま**残ります。通路の奥や角の向こうは、実際にそこまで進まないと見えません。この半径はニコチンゲージの段階に連動し、そわそわ・離脱症状と進むほど狭くなります（すでに開けた範囲が再び閉じることはありません）。
- **未探索エリアにある喫煙所・非常口はマップに出ません。** 探す作業そのものは省略されず、一度見つけた場所を忘れずに済む、という位置づけです。ただし吸い殻と清掃ドローンは嗅覚 Lv5 以上で未探索エリアにも出ます — 収入の機会は探索の対象ではないため、ここだけ例外です。喫煙所は本物とダミーが同じ色なので、**見分けは足で確かめるしかありません**。
- マップは**フロアごとにリセット**されます。次のフロアに進むと白紙に戻ります（敵やアイテムの配置も一新されるため）。
- リザルト表示中は非表示になります。
- **明滅している点が行き先です。** まだ触っていない喫煙所と、開通した非常口だけが明滅します。吸い終わった喫煙所と灰皿撤去済みのダミーは明滅しません。本物とダミーはどちらも候補なので同じように明滅します（見分けは足で確かめるしかありません）。

### 画面の見方（HUD）

**常に出ているのはタバコ（左上）とマップ（右上）の 2 つだけです。** 残りは必要な瞬間だけ現れて、用が済むと消えます。表示が増えていること自体が「危なくなってきた」の合図になります。

| 表示 | 出てくるとき |
| --- | --- |
| タバコ（左上） | 常時。ニコチン残量と段階 |
| マップ（右上） | 常時。右下の `B12` は現在の深度（地下 12 階）。嗅覚 Lv5 では吸い殻と清掃ドローンの点も出ます |
| 百分率 | 60% を切ってから。30% を切ると赤くなります。一服中は常に出ます |
| ♥ HP | 削られてから。満タンに戻って 3 秒で消えます。0%（限界）では明滅します |
| 予備の一本 | 1 本以上持っているとき。30% を切ると `E` が点灯して「いま使え」の合図になります |
| 残り香の距離 | 嗅覚 Lv3 以上が発動している間 |
| 通知（上中央） | フロア到達や非常口の解除など、短い連絡 |

**画面に出さないもの**: 所持ヤニ・撃破数・経過時間・非常口の開通状態。どれもラン中に行動を変えられない値なので、リザルト画面にまとめてあります。非常口が開いたかどうかは、通知とマップの緑の点が伝えます。

高木の内心の吹き出しは自機の頭上に浮かびます。**事実と指示はターミナルとマップ、感情は吹き出し**という住み分けです。

### 敵

| 敵 | 耐久 | 行動 |
| --- | --- | --- |
| **スパイダー**（蜘蛛型） | プラズマ 5 発 | 距離 64 以内に入るとプレイヤーを追尾。接触すると 1 ダメージを与えて弾かれる。撃破すると爆発 |
| **セントリー**（砲台型） | プラズマ 20 発 | 距離 64 以内で接近開始、48 以内でプラズマ弾を発射、24 以内まで近づくと停止して撃ち続ける。硬いので正面から撃ち合うと不利 |

- スパイダーはフロアが進むほど出現数が増えます。床タイルごとの確率ではなく、深度から決まる**総数**を抽選配置するので、深く潜っても際限なく増え続けることはありません。セントリーの出現数も深度とともに緩やかに増えます。
- フロア開始時、プレイヤーのスタート地点から一定のタイル距離より近くには敵もアイテムも湧きません。

### アイテム

| アイテム | 効果 |
| --- | --- |
| **ヘルスパック** | HP +1（最大 5 まで。HP 満タンのときは回復しません） |

床タイルあたりの確率ではなく、**1 フロアあたり 2〜4 個**がランダムに配置されます。ただしフロアを移るとどのみち HP は全回復するので、無理に集めて次のフロアへ持ち越す必要はありません。

### 攻略のヒント

- セントリーは射程 48 で撃ってきます。**壁を盾にして角から撃つ**と被弾を減らせます。
- スパイダーは接触ダメージのみ。敵に向いた状態で `スペース` を押し、**向きを固定したまま後退しながら撃つ**と安全に処理できます。
- 喫煙所を見つけたら、**周囲の敵を先に掃除してから**触れましょう。被弾の無敵時間（2 秒）より一服の所要時間（2.5 秒）の方が長いため、敵に囲まれたままだと一服はいつまでも完了しません。
- ダミーは本物と見分けがつきません。ゲージにまだ余裕があるうちに踏んで**外れを引いておく**と、本命を探す焦りが減ります。
- ゲージがそわそわ・離脱症状に入ると視界とミニマップが狭くなります。段階が変わる前に次の手がかりを探しておくと安全です。

## レベルデータの仕組み

レベルは PNG ではなく、`source/level-generator.ts` が深度とシードから毎回手続き的に生成します。64×64 タイルのグリッドに対して、次の手順で間取りを作ります。

1. 大きさと位置がランダムな部屋を 8〜12 個、互いに 1 タイル以上空けて配置する
2. 隣り合う部屋の中心同士を幅 2 の通路でひとつながりに接続し、さらに 1〜2 本の通路を足してループを作る（袋小路だけだと引き返しが単調になるため）
3. 床に隣接する非床タイルだけを壁にする（床の周囲 1 タイル分の輪郭のみ）
4. 開始部屋からの**タイル距離（BFS）**で全部屋を近い順に並べ、本物の喫煙所・非常口・ダミーの部屋を選ぶ。深度が上がるほど喫煙所は遠くなり、ダミーの数も増える
5. 開始地点から一定距離より遠い床タイルに、敵とアイテムを抽選で配置する。敵の総数は深度でスケールし上限で頭打ちになる（床タイルあたりの確率で撒くと深度が上がったとき全タイルに湧いて破綻するため）。アイテムの数は深度によらず 1 フロアあたり 2〜4 個で一定

生成は決定論的なシードに基づくため、同じ深度・同じシードなら必ず同じ間取りになります。シードはラン開始時に引かれるため、ランをまたぐと同じ深度でも間取りは変わります。

## ビルド

```bash
npm install
npm run build
```

型チェック（`tsc --noEmit`）を実行したうえで `dist/` に本番用ファイルを出力します。`dist/` 全体は約 560KB で、そのうち約 450KB はタイトルと死亡画面のイラスト 2 枚です。画像のうち 4096 バイト未満のもの（死亡画面の小さいアイコン）は Vite の既定設定でデータ URI としてバンドルに埋め込まれ、それより大きいものは `dist/assets/` にハッシュ付きの別ファイルとして出力されます。

```bash
npm run preview
```

`dist/` の内容をローカルで確認できます。表示された URL を開いてください。

テストと型チェック:

```bash
npm test
npm run typecheck
```

## 日本語アレンジのメモ

- **テキストの日本語化**: 完了。画面に出る文言は `source/terminal.ts`（イントロ / ストーリー / リザルト画面）、`source/game.ts`（フロア到達時の通知）、`source/entity-smoking-area.ts`（一服・ダミーの通知）、`source/entity-exit.ts`（非常口通過の通知）、`source/main.ts`（`起動中...`）にあります
  - 作者名・URL・`JS13K` などの固有名詞と、`CPU: PL(R) Q-COATL 7240 @ 12.6 THZ` のような疑似スペックはそのまま残しています
  - ターミナル演出では `_` が改行 10 個（= 約 1 秒の待ち）に展開されるため、**文中に `_` を書かないこと**（`terminal_prepare_text` を参照）
- **タイトルまわり**: 完了。`index.html` の `<title>` を `TAKAGI ACTION` に変更済み
- **表示スタイルの調整**: 現状は不要。ターミナル表示（`#a`）は `white-space: nowrap` の 1 行表示・等幅前提ですが、日本語の各行は最長でも横幅の約半分で収まっているため折り返しは発生しません。今後長い行を足す場合は要注意
- **難易度調整**: フロアは無限に手続き生成されるため、新しいレベルを手作業で追加する必要はありません。部屋数・敵の総数・ニコチン減少速度などのパラメータは `source/level-generator.ts` と `source/nicotine.ts` に集約されています（詳細は上記「レベルデータの仕組み」を参照）
- **ファイルサイズの制約について**: 13KB は js13k のルールです。このリポジトリはすでに js13k 提出用ビルド（旧 `build.sh`）を持たず、Vite の通常ビルドでサイズ制約なく配信するため、日本語テキストの増量を気にせず自由にアレンジできます
